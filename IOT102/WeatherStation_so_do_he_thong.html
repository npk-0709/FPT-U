Weather Station — Trạm quan trắc thời tiết mini dùng LoRa & ESP8266

Sơ đồ hệ thống IoT dựng theo báo cáo đồ án: mô hình 3 lớp Sensor → LoRa Node (ESP8266 + SX1278) → Gateway (ESP8266 + SX1278, có Wi‑Fi) → Cloud, đo nhiệt độ/độ ẩm/áp suất/lượng mưa, hiển thị dashboard thời gian thực và cảnh báo qua Telegram khi vượt ngưỡng.

1. Kiến trúc tổng thể — bốn khối chính

Node đặt ngoài trời để đo, Gateway đặt trong nhà nơi có Wi‑Fi ổn định; hai bên liên lạc bằng LoRa điểm–điểm (không dùng LoRaWAN).

KhốiThành phầnNhiệm vụ chính
1. Cảm biếnBME280 (nhiệt độ/độ ẩm/áp suất), DHT22 (tùy chọn), cảm biến mưa (gầu lật hoặc FC‑37)Chuyển đại lượng vật lý thành tín hiệu điện (I2C, số, tương tự, xung).
2. LoRa NodeESP8266 + module LoRa SX1278 + nguồn (pin/adapter)Đọc cảm biến theo chu kỳ, lọc và kiểm tra dữ liệu, tính lượng mưa, đóng gói và phát qua LoRa.
3. GatewaySX1278 + ESP8266 (có Wi‑Fi)Nhận gói LoRa, giải mã, so ngưỡng, đẩy dữ liệu lên cloud, gửi cảnh báo.
4. Cloud & người dùngThingSpeak (hoặc MQTT + Grafana), Telegram BotLưu trữ, hiển thị dashboard, nhận thông báo trên điện thoại.
Yêu cầu đề bài (bám sát 4 chức năng): (1) LoRa node thu thập dữ liệu từ cảm biến · (2) LoRa node xử lý và truyền đến gateway (gateway trang bị ESP8266) · (3) Dữ liệu được tải lên cloud để trực quan hóa · (4) Khi bất kỳ thông số nào vượt ngưỡng định trước, hệ thống gửi cảnh báo/thông báo. Phạm vi bản demo: 1 node + 1 gateway, LoRa điểm–điểm, dashboard trên cloud, cảnh báo qua Telegram.

2. Lưu đồ firmware Node và Gateway

Node chạy vòng lặp đọc – xử lý – gửi theo chu kỳ (mặc định 60 giây); Gateway lắng nghe liên tục bằng parsePacket() (chế độ polling, không dùng ngắt DIO0) rồi giải mã, đẩy cloud và so ngưỡng.

Gợi ý khi lập trình vòng lặp: dùng millis() thay cho delay() dài để không bỏ lỡ xung của gầu lật đo mưa (xử lý bằng ngắt FALLING, chống dội 50–100 ms). Với gateway, chỉ cần đảm bảo loop() không bị chặn để không mất gói LoRa. Node tắt Wi‑Fi (WiFi.mode(WIFI_OFF)) để tiết kiệm điện vì không cần dùng.
Xử lý mưa tích lũy: node gửi lượng mưa tích lũy từ lúc bật nguồn (không phải mưa trong chu kỳ) — nếu mất một gói, gateway vẫn tính lại đúng tổng mưa nhờ chênh lệch giữa hai gói kế tiếp. Nếu giá trị mới nhỏ hơn giá trị cũ thì gateway hiểu là node vừa khởi động lại.

4. Sơ đồ đấu nối chân ESP8266 NodeMCU

Cả Node và Gateway đều dùng ESP8266 NodeMCU + SX1278 đấu giống hệt nhau qua SPI; khác nhau ở việc Node thêm cảm biến (BME280 · mưa · DHT22) còn Gateway thêm Wi‑Fi, OLED/LED/buzzer.

Những điều dễ làm hỏng module LoRa: (1) không phát khi chưa gắn ăng‑ten — công suất phản xạ có thể hỏng tầng khuếch đại; (2) không cấp 5V vào chân VCC hoặc chân tín hiệu (chip chỉ 1,8–3,7V); (3) nguồn 3,3V yếu/nhiễu làm module reset khi phát — thêm tụ 100–470 µF sát chân nguồn; (4) chân SPI cắm/hàn lỏng gây lỗi "LoRa init failed" hoặc chạy chập chờn.
