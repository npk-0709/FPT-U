// WarehouseManager.issueStock() pattern
while (remaining > 0
    && !batchQueue.isEmpty()) {
  Batch b = batchQueue.peek();
  if (b.qty <= remaining) {
    remaining -= b.qty;
    batchQueue.dequeue();     // full
  } else {
    b.reduceQuantity(remaining); // partial
    remaining = 0;
  }
}

Entry #030 — Orphaned Reference Pattern: Delete Safety

AI confirmed zero-stock guard is sufficient. Human detected additional structural risk: orphaned StockTransaction records in TransactionLog.

What AI confirmed (correct but incomplete):

What AI missed (orphaned reference risk):
⚠ Architectural Limitation Identified by Human (AI missed this): The zero-stock guard protects inventory but not audit trail integrity. When all batches expire and product is deleted, TransactionLog records for that barcode become orphaned (referencing a non-existent product). Production solution: soft-delete (archive) rather than hard-delete when TX records exist.
