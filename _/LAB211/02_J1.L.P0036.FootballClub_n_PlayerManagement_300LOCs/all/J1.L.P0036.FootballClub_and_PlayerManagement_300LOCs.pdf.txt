Title 
 
Football Club & Player Management 
Background  
A football tournament called the European Elite League (EEL) needs to manage information about 
participating clubs and players. Therefore, they hired FTC Software Company, where you work as a 
professional Java developer, to implement this project as a console-based application. 
The system stores data in two text files, automatically loads them on startup, and provides a thirteenth 
function that allows users to reload the data on demand: 
- 
clubs.txt – containing football club information 
- 
players.txt – containing player information 
Students are required to analyze and design the program using an Object-Oriented Programming (OOP) 
approach. The development process must incorporate OOP principles, such as abstraction, polymorphism, 
encapsulation, and inheritance.

Constraints 
1-  Constraints on Clubs 
a. Club ID must be unique 
b. Club ID format: CL-xxxx (e.g., CL-0001) 
c. Club name cannot be empty 
d. Sponsor brand cannot be empty 
e. Budget must be a positive real number 
2-  Constraints on Players 
a. Player ID must be unique 
b. Player ID format: Pxxxx (e.g., P0001) 
c. Club ID must exist in the club list 
d. Player name cannot be empty 
e. Position must be one of the following values: Goalkeeper, Defender, Midfielder, Forward, Winger 
(case-insensitive). 
f. Shirt number must be an integer between 1 and 99 and unique within the same club 
Program Specifications 
The program’s menu system includes 14 functions that allow users to control the application, as described 
below. 
1. List of all clubs 
2. Add a new club 
3. Search for a club by ID 
4. Update a club by ID 
5. List of all clubs with budget ≤ input value 
6. List all players in ascending order of club names, if same club, sort by shirt number ascending. 
7. Search players by partial player name 

3 
 
8. Add a new player 
9. Remove a player with ID 
10. Update a player with an ID 
11. List all players by a specific position 
12. Save data to files 
13. Load data from files 
14. Quit program
