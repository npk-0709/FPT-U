## 1. Giới thiệu

Trong Java, `List` là một **interface** thuộc `java.util`, đại diện cho một danh sách có thứ tự, cho phép phần tử trùng lặp.

`ArrayList` là **lớp triển khai phổ biến nhất** của `List`, sử dụng mảng động bên trong.

```
java.util.Collection
    └── java.util.List (interface)
            ├── ArrayList
            ├── LinkedList
            └── Vector
```

### Import cần thiết

```java
import java.util.List;
import java.util.ArrayList;
import java.util.Collections;
```

## 2. List Interface

`List` là interface — bạn **không thể khởi tạo trực tiếp**, nhưng nên dùng nó làm kiểu khai báo để code linh hoạt hơn.

```java
// ✅ Khuyến nghị: khai báo kiểu List, khởi tạo bằng ArrayList
List<String> danhSach = new ArrayList<>();

// ❌ Không nên: khai báo trực tiếp bằng ArrayList (kém linh hoạt)
ArrayList<String> danhSach = new ArrayList<>();
```

> **Lý do:** Nếu sau này bạn muốn đổi sang `LinkedList`, chỉ cần thay phần khởi tạo mà không cần sửa toàn bộ code.

## 3. ArrayList

### Khởi tạo ArrayList

```java
// Danh sách rỗng
List<String> fruits = new ArrayList<>();

// Khởi tạo với dung lượng ban đầu (tối ưu hiệu năng)
List<Integer> numbers = new ArrayList<>(100);

// Khởi tạo từ một Collection khác
List<String> copy = new ArrayList<>(fruits);

// Khởi tạo với giá trị ban đầu (dùng Arrays.asList)
import java.util.Arrays;
List<String> colors = new ArrayList<>(Arrays.asList("Đỏ", "Xanh", "Vàng"));

// Java 9+: dùng List.of (danh sách bất biến)
List<String> fixed = List.of("A", "B", "C");
```

### Kiểu dữ liệu Generic

ArrayList sử dụng **Generics** (`<T>`) — chỉ định rõ kiểu dữ liệu để tránh lỗi runtime:

```java
List<Integer>  soNguyen  = new ArrayList<>();
List<Double>   soThuc    = new ArrayList<>();
List<String>   chuoi     = new ArrayList<>();
List<Boolean>  boolean_  = new ArrayList<>();

// Dùng với Object tự định nghĩa
List<SinhVien> danhSachSV = new ArrayList<>();
```

## 4. Các Thao Tác Cơ Bản

### Thêm phần tử — `add()`

```java
List<String> list = new ArrayList<>();

list.add("Java");           // Thêm vào cuối
list.add("Python");
list.add("C++");

list.add(1, "Kotlin");      // Thêm vào vị trí index = 1
// Kết quả: ["Java", "Kotlin", "Python", "C++"]

// Thêm nhiều phần tử cùng lúc
list.addAll(Arrays.asList("Go", "Rust"));
```

### Truy cập phần tử — `get()`

```java
String first = list.get(0);   // Lấy phần tử đầu tiên
String last  = list.get(list.size() - 1); // Lấy phần tử cuối
```

### Cập nhật phần tử — `set()`

```java
list.set(0, "JavaScript");   // Thay thế phần tử tại index 0
```

### Xóa phần tử — `remove()`

```java
list.remove(0);              // Xóa theo index
list.remove("Python");       // Xóa theo giá trị (phần tử đầu tiên tìm thấy)
list.removeAll(Arrays.asList("Go", "Rust")); // Xóa nhiều phần tử
list.clear();                // Xóa toàn bộ
```

### Kiểm tra — `contains()`, `isEmpty()`, `size()`

```java
boolean coJava = list.contains("Java");  // Kiểm tra có tồn tại không
boolean rong   = list.isEmpty();         // Kiểm tra danh sách rỗng
int     soLuong = list.size();           // Số lượng phần tử

int viTri = list.indexOf("Java");        // Tìm index (trả về -1 nếu không có)
```

### Chuyển đổi sang mảng

```java
String[] mang = list.toArray(new String[0]);
```

## 5. Duyệt Phần Tử

### Cách 1: Vòng lặp `for` truyền thống

```java
for (int i = 0; i < list.size(); i++) {
    System.out.println(i + ": " + list.get(i));
}
```

### Cách 2: Enhanced `for-each` *(khuyến nghị)*

```java
for (String item : list) {
    System.out.println(item);
}
```

### Cách 3: `Iterator`

```java
import java.util.Iterator;

Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String item = it.next();
    if (item.equals("Java")) {
        it.remove(); // Xóa an toàn trong khi duyệt
    }
}
```

### Cách 4: `forEach` với Lambda *(Java 8+)*

```java
list.forEach(item -> System.out.println(item));

// Hoặc dùng method reference
list.forEach(System.out::println);
```

### Cách 5: Stream API *(Java 8+)*

```java
import java.util.stream.Collectors;

// Lọc và in
list.stream()
    .filter(s -> s.startsWith("J"))
    .forEach(System.out::println);

// Lọc và tạo danh sách mới
List<String> result = list.stream()
    .filter(s -> s.length() > 4)
    .collect(Collectors.toList());
```

## 6. Sắp Xếp và Tìm Kiếm

### Sắp xếp với `Collections.sort()`

```java
import java.util.Collections;

List<Integer> numbers = new ArrayList<>(Arrays.asList(5, 2, 8, 1, 9));

Collections.sort(numbers);               // Tăng dần: [1, 2, 5, 8, 9]
Collections.sort(numbers, Collections.reverseOrder()); // Giảm dần
```

### Sắp xếp với `list.sort()` và Lambda *(Java 8+)*

```java
List<String> names = new ArrayList<>(Arrays.asList("Hà", "An", "Bình", "Cúc"));

names.sort((a, b) -> a.compareTo(b));              // Tăng dần A-Z
names.sort((a, b) -> b.compareTo(a));              // Giảm dần Z-A
names.sort(Comparator.naturalOrder());             // Tăng dần
names.sort(Comparator.reverseOrder());             // Giảm dần
```

### Sắp xếp danh sách Object

```java
class SinhVien {
    String ten;
    double gpa;
    // constructor, getter...
}

List<SinhVien> svList = new ArrayList<>();
// Sắp xếp theo GPA tăng dần
svList.sort(Comparator.comparingDouble(SinhVien::getGpa));
// Sắp xếp theo tên rồi đến GPA
svList.sort(Comparator.comparing(SinhVien::getTen)
                      .thenComparingDouble(SinhVien::getGpa));
```

### Tìm kiếm nhị phân — `Collections.binarySearch()`

```java
// ⚠️ Phải sort trước khi tìm kiếm nhị phân
Collections.sort(numbers);
int index = Collections.binarySearch(numbers, 5);
// Trả về index nếu tìm thấy, số âm nếu không có
```

## 7. ArrayList vs LinkedList

| Tiêu chí | ArrayList | LinkedList |
|---|---|---|
| **Cấu trúc** | Mảng động | Danh sách liên kết đôi |
| **Truy cập ngẫu nhiên** | ✅ O(1) nhanh | ❌ O(n) chậm |
| **Thêm/xóa ở cuối** | ✅ O(1) | ✅ O(1) |
| **Thêm/xóa ở giữa** | ❌ O(n) chậm | ✅ O(1) nhanh |
| **Bộ nhớ** | Tiết kiệm hơn | Tốn hơn (lưu 2 pointer) |
| **Khi nào dùng** | Đọc nhiều, ít thêm/xóa giữa chừng | Thêm/xóa đầu/cuối thường xuyên |

```java
// Ví dụ dùng LinkedList
import java.util.LinkedList;

List<String> linkedList = new LinkedList<>();
linkedList.add("A");
linkedList.add("B");
```

## 8. Một Số Mẹo Hữu Ích

### Tạo danh sách bất biến (Immutable List)

```java
// Java 9+
List<String> immutable = List.of("A", "B", "C");
// immutable.add("D"); // ❌ Sẽ ném UnsupportedOperationException

// Java 8 trở xuống
List<String> immutable8 = Collections.unmodifiableList(new ArrayList<>(list));
```

### Sao chép danh sách

```java
// Shallow copy
List<String> copy1 = new ArrayList<>(original);
List<String> copy2 = List.copyOf(original); // Java 10+, bất biến
```

### Gộp hai danh sách

```java
List<String> list1 = new ArrayList<>(Arrays.asList("A", "B"));
List<String> list2 = Arrays.asList("C", "D");
list1.addAll(list2);  // list1 = ["A", "B", "C", "D"]
```

### Lấy danh sách con — `subList()`

```java
List<String> sub = list.subList(1, 4); // Lấy từ index 1 đến 3
```

### Xáo trộn danh sách

```java
Collections.shuffle(list); // Xáo trộn ngẫu nhiên
```

### Tần suất và tần số

```java
int freq = Collections.frequency(list, "Java"); // Đếm số lần xuất hiện
String max = Collections.max(list);             // Phần tử lớn nhất
String min = Collections.min(list);             // Phần tử nhỏ nhất
```

## Ví Dụ Tổng Hợp

```java
import java.util.*;
import java.util.stream.Collectors;

public class Main {
    public static void main(String[] args) {
        // Khởi tạo
        List<String> monHoc = new ArrayList<>(
            Arrays.asList("Toán", "Lý", "Hóa", "Sinh", "Văn", "Anh")
        );

        // Thêm
        monHoc.add("Tin học");
        monHoc.add(0, "GDCD");

        // Xóa
        monHoc.remove("Sinh");

        // Kiểm tra
        System.out.println("Có môn Toán: " + monHoc.contains("Toán"));
        System.out.println("Số môn học: " + monHoc.size());

        // Sắp xếp
        Collections.sort(monHoc);

        // Duyệt
        System.out.println("Danh sách môn học:");
        monHoc.forEach(mon -> System.out.println("  - " + mon));

        // Lọc bằng Stream
        List<String> monNgan = monHoc.stream()
            .filter(mon -> mon.length() <= 3)
            .collect(Collectors.toList());

        System.out.println("Môn có tên ngắn (<= 3 ký tự): " + monNgan);
    }
}
```

**Output:**
```
Có môn Toán: true
Số môn học: 7
Danh sách môn học:
  - Anh
  - GDCD
  - Hóa
  - Lý
  - Tin học
  - Toán
  - Văn
Môn có tên ngắn (<= 3 ký tự): [Anh, Hóa, Lý, Văn]
```

---

> 💡 **Tóm tắt:** Dùng `List<T>` làm kiểu khai báo và `ArrayList` làm mặc định. Chỉ chuyển sang `LinkedList` khi cần thêm/xóa nhiều ở đầu/giữa danh sách. Tận dụng Stream API (Java 8+) để xử lý dữ liệu ngắn gọn và hiệu quả.

## 9. Non-Generic ArrayList (Raw Type)

### Non-Generic là gì?

Trước Java 5, Java chưa có **Generics**. Lúc đó `ArrayList` lưu trữ mọi thứ dưới dạng `Object`, người dùng phải **ép kiểu (cast)** thủ công khi lấy phần tử ra.

Ngày nay, dùng raw type bị coi là **bad practice** vì mất type safety, nhưng hiểu nó giúp bạn:
- Hiểu cách Java hoạt động bên trong
- Làm việc với code Java cũ (legacy code)
- Nắm vững lý do Generics ra đời

### Raw Type ArrayList (Không dùng `<T>`)

```java
import java.util.ArrayList;

// ⚠️ Raw type — không có kiểu Generic
ArrayList danhSach = new ArrayList();

danhSach.add("Java");   // Thêm String
danhSach.add(42);        // Thêm Integer — không báo lỗi!
danhSach.add(3.14);      // Thêm Double — không báo lỗi!

// Khi lấy ra phải ép kiểu thủ công
String s = (String) danhSach.get(0);  // ✅ OK
String x = (String) danhSach.get(1);  // ❌ ClassCastException lúc runtime!
```

> **Vấn đề:** Compiler không báo lỗi, nhưng chương trình crash tại runtime — rất nguy hiểm.

### Tự xây dựng Custom Non-Generic ArrayList

Thay vì dùng raw `ArrayList`, bạn có thể tự xây dựng một danh sách động bằng mảng `Object[]`:

```java
public class CusArrListNonGeneric {

    private Object[] data;              // Mảng lưu dữ liệu (kiểu Object)
    private int size;                   // Số phần tử hiện có
    private static final int DEFAULT_CAPACITY = 10;

    public CusArrListNonGeneric() {
        data = new Object[DEFAULT_CAPACITY];
        size = 0;
    }

    // Tăng dung lượng khi đầy
    private void grow() {
        int newCapacity = data.length * 2;
        Object[] newData = new Object[newCapacity];
        for (int i = 0; i < size; i++) {
            newData[i] = data[i];
        }
        data = newData;
    }

    // Thêm phần tử
    public void addEmployee(Employee emp) {
        if (size == data.length) grow();
        data[size++] = emp;
    }

    // Lấy phần tử — phải ép kiểu từ Object
    public Employee get(int index) {
        return (Employee) data[index]; // cast thủ công
    }

    public int size() { return size; }
}
```

### Ép kiểu (Casting) — Điểm mấu chốt

Khi dùng `Object[]`, mọi phần tử đều được lưu dưới dạng `Object`. Để dùng được, phải **ép kiểu (downcast)**:

```java
// Lấy phần tử -> ép kiểu thủ công
Employee emp = (Employee) data[i];

// Nếu ép kiểu sai -> RuntimeException
Object obj = "Xin chào";
Employee emp2 = (Employee) obj; // ❌ ClassCastException!

// Kiểm tra trước khi ép kiểu (an toàn hơn)
if (data[i] instanceof Employee) {
    Employee emp3 = (Employee) data[i]; // ✅
}
```

### So sánh Generic vs Non-Generic

| Tiêu chí | Generic `ArrayList<Employee>` | Non-Generic `Object[]` |  
|---|---|---|
| **Khai báo** | `ArrayList<Employee>` | `Object[]` hoặc raw `ArrayList` |
| **Type safety** | ✅ Compiler kiểm tra | ❌ Chỉ phát hiện lúc runtime |
| **Ép kiểu** | Tự động | Phải ép kiểu thủ công `(Employee)` |
| **Lỗi** | Compile-time error | `ClassCastException` tại runtime |
| **Cảnh báo** | Không có | Compiler warning: *unchecked cast* |
| **Hiệu năng** | Như nhau (autoboxing) | Như nhau |
| **Khuyến nghị** | ✅ Luôn dùng | ❌ Tránh dùng (trừ legacy code) |

### Ví dụ So Sánh Trực Tiếp

```java
// ✅ GENERIC — an toàn, rõ ràng
List<Employee> generic = new ArrayList<>();
generic.add(new Employee("E01", "An", "IT", 50000));
Employee emp = generic.get(0); // Không cần cast

// ⚠️ NON-GENERIC — phải cast thủ công
CusArrListNonGeneric nonGeneric = new CusArrListNonGeneric();
nonGeneric.addEmployee(new Employee("E01", "An", "IT", 50000));
Employee emp2 = nonGeneric.get(0); // (Employee) cast bên trong get()
```

### Sắp xếp trong Non-Generic ArrayList

Không có `Comparator<T>` tổng quát, ta tự cài thuật toán **Bubble Sort** với ép kiểu:

```java
// Bubble Sort tăng dần theo lương
public void sortBySalaryByAsc() {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - 1 - i; j++) {
            Employee e1 = (Employee) data[j];      // ép kiểu
            Employee e2 = (Employee) data[j + 1];  // ép kiểu
            if (e1.getBasic_salary() > e2.getBasic_salary()) {
                // hoán đổi
                Object temp = data[j];
                data[j]     = data[j + 1];
                data[j + 1] = temp;
            }
        }
    }
}
```

> 💡 **Kết luận:** Hiểu non-generic giúp bạn nắm rõ lý do Generics tồn tại — đó là **loại bỏ ClassCastException tại runtime** bằng cách kiểm tra kiểu ngay từ lúc biên dịch. Trong code hiện đại, **luôn dùng Generic**.
